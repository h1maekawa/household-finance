# Product Vision

## プロダクト定義

Flow+ は **Personal Finance OS**（個人向け金融OS）です。家計簿アプリではありません。

家計簿は「何に使ったか」を見るものです。Flow+ が答えるのはその先です。

- 今月あといくら使えるか
- いくら貯金できるか
- いくら資産形成に回せるか
- 支払いは大丈夫か
- 目標は達成できるか
- このまま進むと将来いくらになるか

これらを1つのアプリで判断できる状態を完成形とします。

## 一元管理する対象

収入 / 支出 / 固定費 / クレジットカード / 銀行残高 / 貯金 / 資産 / 投資 / 将来目標。

「現在いくらあるか」だけでなく「これからどうお金を配分すべきか」まで分かることを目的にします。

## Money Flow

お金の流れを1本の滝として扱います。これがアプリ全体の基本構造です。

```
収入
 ↓
生活固定費
 ↓
目標貯金
 ↓
投資・資産形成
 ↓
予備費
 ↓
自由に使えるお金
```

この構造は `lib/services/money-plan.ts` に実装済みで、そこが唯一の正です。
画面やAPIごとに別の計算式を持たせません。

## プロダクト構成

```
Flow+
 ├── 家計管理
 ├── キャッシュフロー
 ├── 予算
 ├── Goals
 ├── 資産管理
 ├── 資産形成プラン
 ├── 将来予測
 └── AI Coach
```

## 実装状況

ドキュメントと実装の乖離を作らないため、現時点の状態を明記します。

| 領域 | 状態 |
|---|---|
| 家計管理・取引記録 | 実装済み |
| キャッシュフロー・予算 | 実装済み（`budget-engine`） |
| Money Plan（お金の流れ） | 実装済み（`money-plan`・`/plan`） |
| Goals・進捗判定 | 実装済み（`goal-progress`） |
| 投資可能額 | 実装済み（`investment-capacity`） |
| AI Coach | 実装済み。ただし現状はルールベース（`coach-rules`） |
| 貯金余力／資産形成余力の分離 | 実装済み（`investment-capacity`） |
| 現金防衛資金 | 実装済み（`emergency-fund`） |
| 将来シミュレーション | 計算のみ実装（利回り0%固定）。UIはPhase 4 |
| 資産形成プラン（統合ビュー） | 計算のみ実装（`asset-planning`）。UIはPhase 4 |
| Subscription（Free / Pro） | 未実装（現状は買い切り） |

未実装の機能を「利用できます」と表示しません。LPやUIで触れる場合は「近日公開」「Proで順次提供予定」とします。

## プラン

| プラン | 位置づけ |
|---|---|
| Free | 基本家計簿・収支管理・簡易Dashboard |
| Pro | 資産管理・Goals・資産形成プラン・AI Coach・外部連携・将来シミュレーション |
| legacy_pro | fail-closed 化以前からの既存ユーザー。現在の機能を維持し、Subscription 不要 |

料金はコードにハードコードせず Stripe Price ID で管理します。詳細は [BILLING.md](BILLING.md)。

## やらないこと

以下は実装しません。金融OSであっても、資金移動と売買判断は人間の領域に残します。

- 株式の自動売買、金融商品の自動購入、証券口座からの自動注文
- 投資商品の具体的な売買判断
- AIによる投資金額の決定
- AI Company からの金融データ書き換え

## 立ち位置

Flow+ は個人の金融データの **Source of Truth** です。
AI Company をはじめとする上位の Personal OS からは、集計済みのサマリを read-only で参照します。
詳細は [AI_COMPANY_INTEGRATION.md](AI_COMPANY_INTEGRATION.md)。
